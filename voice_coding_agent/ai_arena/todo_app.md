# TODO Application

A simple and effective application to manage your daily tasks.

## Features
- Add, edit, and delete tasks
- Mark tasks as complete or incomplete
- Task filtering (e.g., completed, pending)
- Persistent storage

## Installation
1. Clone this repository
2. Install dependencies (see below for technologies used)
3. Run the application

## Usage
- Launch the app and start adding your tasks
- Use the filter options to view specific tasks
- Edit or delete tasks as needed
